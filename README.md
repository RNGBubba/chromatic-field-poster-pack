# Chromatic Field

Chromatic Field is an original p5.js generative poster pack: four deterministic systems that turn a numeric seed into a composed 18×24 wall print. It is a small, browser-native art instrument, not a game or simulation.

## Included fields

- **Lattice Bloom** — measured marks and warm signal points.
- **Signal Orchard** — overlapping chromatic nodes and connective stems.
- **Tidal Glyph** — nested, breathing contours around a central point.
- **Night Geometry** — additive angular planes on a deep field.

Open `index.html` in a browser. Pick a field, enter a seed, and export a PNG. The preview uses a 720×960 canvas, a 3:4 ratio suitable for 18×24 inch output at 40 pixels/inch; for a true 300 DPI print, use the included source to scale the composition in a raster editor or extend the canvas dimensions in `sketch.js`.
